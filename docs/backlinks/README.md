## 提交原则

1. **免费优先**：只使用 $0 档位，不购买 Verified、Featured、加急审核或首页展示。
2. **无需返链**：站点若要求把其链接放到 QuickSend 官网，或把“加友链”作为收录前提，直接排除。
3. **不重复提交**：提交前先站内搜索 `QuickSend` 与 `quicksend.chat`。
4. **不虚构信息**：只使用本文档“产品事实”与“标准文案”中的内容。
5. **记录结果**：每次提交后立即更新下方台账，保存提交页截图或邮件确认。
6. **区分链接属性**：`nofollow` 仍可带来发现与引荐流量，但不能当作传递权重的 dofollow 外链。
